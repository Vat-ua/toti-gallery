# Font assets

Official, unmodified Google Fonts files downloaded on 2026-10-24.
Served locally through `@font-face`; no runtime Google Fonts requests.

- DM Sans: normal variable weight 100–1000, Google Fonts version v17.
- Manrope: normal variable weight 200–800, Google Fonts version v20.
- Format: WOFF2; Latin and Latin Extended subsets for each family.
- Unicode ranges and weight descriptors follow the official CSS response.
- Both families use SIL Open Font License 1.1; the license texts are included.

Source CSS:
https://fonts.googleapis.com/css2?family=DM+Sans:wght@100..1000&family=Manrope:wght@200..800&display=swap

Requested with a modern Chrome user agent to obtain variable WOFF2 files.
Latin contains Portuguese precomposed accented characters. The extended subset
also supports additional Latin-script names; other scripts use existing fallbacks.

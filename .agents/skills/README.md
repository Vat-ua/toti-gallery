# Project skills

Official Neon reference skills installed for this project:

- `neon`: platform overview and routing to feature-specific skills.
- `neon-postgres`: connections, SQL, schemas and migrations.
- `neon-postgres-branches`: isolated development and test branches.
- `neon-object-storage`: image/file uploads, buckets, access and storage branching.

Source: https://github.com/neondatabase/agent-skills
Revision: `ff9903df951dd07141a7b4edde459b41acf5d122`

Each skill has its own `SKILL.md` and any bundled reference files.
Project rules in [AGENTS.md](../../AGENTS.md) and
[docs/environments.md](../../docs/environments.md) take precedence over general
examples. Installing these skills grants no permission to change infrastructure,
credentials or database data. MCP is not configured by this installation.
